Personal · OVH VPS

Self-hosted observability stack

Metrics, logs and security of an Ubuntu VPS brought together in Grafana, behind Cloudflare Zero Trust access. A real-world training ground for monitoring.

PROJECT CARDOBS-VPS

OVH VPS · Ubuntu

Access
Cloudflare Zero Trust + one-time PIN
Security
SSH ed25519 · fail2ban

Context

At work, I use Zabbix and Aruba Instant On to monitor the network. On my own VPS, I wanted to build a complete monitoring setup myself with the Grafana stack: system and container metrics, centralised logs, and an eye on the attacks any Internet-facing server receives.

Architecture

Two collection pipelines, one interface, no admin port open to the public.

Dashboards

Each dashboard is built to answer one specific question.

A third dashboard plots the IP addresses banned by fail2ban on a map, geolocated with the GeoLite2 database.

Hardening

Monitoring an exposed server starts with shrinking its attack surface.

Grafana access

Grafana is not exposed directly: it is reached through a Cloudflare Zero Trust tunnel, protected by a one-time PIN.

Hardened SSH

ed25519 key authentication only, password login disabled.

fail2ban

Addresses that keep failing are banned automatically, and every ban shows up in the dashboards.

What it shows

  • Visible Over 2 days: 1.22k failed SSH login attempts and 134 addresses banned. The Internet's background noise becomes measurable.
  • Stable At the time of the capture, the server had been running for 11.1 weeks without a reboot.
  • Centralised Metrics and logs can be viewed in one place, through a single protected entry point.
